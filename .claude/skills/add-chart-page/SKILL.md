# Add or change a reference chart page

Chart pages are generated by `tools/gen_charts.py` from `tools/charts-data.json`. That JSON holds the
same tables the InCost app uses, so the site and the app agree. `tools/check_charts.py` checks the numbers
**independently**, against values typed in from the published standards.

1. Data first. Take the table from the InCost library (the owner exports it) or from the published standard.
   Name the standard (ISO, ANSI/ASME, ASTM, EN) and its edition. Never guess numbers.
2. Add the data under a new key in `tools/charts-data.json`.
3. In `tools/gen_charts.py`, write a function `p_<name>()` like `p_angle()`. It returns
   `page(fname, title, h1, lead, body, faqs, meta_desc, seo_title, dl_src, article)`.
   Add that function to the tuple in `if __name__ == '__main__':`. The page should include
   - a short lead: what the table is for, in shop words,
   - the table (`table(...)`), plus `finder(...)` if the table is long,
   - a sources line (`.src`), 3–5 FAQs, and a link to the matching InCost feature,
   - the entry in `CHARTS`, so the other pages link to it.
   Put US/inch columns first where the US shop floor uses them.
4. In `tools/check_charts.py`, add independent checks: reference values from the standard and closed-form
   formulas where they exist. Don't read `charts-data.json` there — the check has to be independent.
5. Run `python3 tools/gen_charts.py`, then `python3 tools/check_charts.py`. Both must pass with 0 fail.
6. Add the page to `sitemap.xml`, then run `python3 tools/check_site.py`.
7. Tell the owner which standard the numbers come from and how many checks were added.
